# AL Company Architects

Frontend web site for AL Company Valjevo. 

https://alcompany.vercel.app/

## Local development

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run build
npm run preview
npm run lint
npm test
```

## Tech stack

- Vite
- TypeScript
- React
- React Router
- Tailwind CSS
- shadcn/ui
