# AL Company Architects

Frontend web app for AL Company Architects.

## Local development

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run build
npm run preview
npm run lint
npm test
```

## Tech stack

- Vite
- TypeScript
- React
- React Router
- Tailwind CSS
- shadcn/ui


## Disabled features

The floating AI Assistant widget is disabled and kept in `_disabled/ai-assistant/` (excluded from build, tsconfig and ESLint). See the README in that folder for restore steps.
